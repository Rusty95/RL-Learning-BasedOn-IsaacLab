Soft Actor-Critic

SAC：一边追求奖励，一边保留探索

SAC 是连续控制里非常常用的 off-policy Actor-Critic。它不只最大化 reward，还最大化策略熵，让智能体既会做事，也别太早变得死板。

先和 PPO 对比

维度 PPO SAC
数据使用 On-policy，当前策略采样的数据用几轮就丢。 Off-policy，数据进入 replay buffer，可以反复抽样训练。
动作空间 离散、连续都能用，但机器人连续控制里常需要较多样本。 特别适合连续动作控制，例如力矩、速度、末端位姿增量。
稳定技巧 ratio clip、GAE、KL 监控。 双 Q、target network、最大熵、重参数化采样。
探索方式 entropy bonus 是辅助项。 entropy 是目标函数的一部分，探索被系统性建模。

一句话：PPO 学的是“别让新策略离旧策略太远”；SAC 学的是“奖励要高，同时策略要保持足够随机”。

SAC 的核心：最大熵强化学习

普通 RL 最大化未来奖励。SAC 多加了一项 entropy，让策略不要只追求一个确定动作，而是在多个可行动作之间保留探索。这样在复杂连续控制里更不容易卡死。

熵越大，动作分布越分散；熵越小，策略越确定。SAC 用温度参数 α 控制“奖励”和“探索”的权衡。

普通 RLmaximize E[Σt γt rt] 最大熵 RLmaximize E[Σt γt(rt + α H(π(·|st)))] 连续策略at ~ π(a|s) = Normal(μ(s), σ(s))

小演示：α 怎么影响探索

拖动温度 α。α 越大，策略越重视 entropy，动作分布越宽；α 越小，策略越贪心，更贴近当前 Q 最大的动作。

SAC 的三大模块

Actor

随机高斯策略

Actor 输入状态，输出动作分布参数 mean 和 log_std。训练时采样动作，评估时通常用均值动作。

Twin Q

两个 Q 网络

SAC 不学单个 V(s)，而是学 Q(s,a)。两个 Q 网络取较小值，可以缓解高估问题。

Replay Buffer

经验复用

每次交互得到 (s,a,r,s_next,done) 后放进 buffer。训练时随机抽 batch，样本效率比 PPO 高。

SAC 完整训练流程

  1. 用 Actor 和环境交互

    当前状态 s 输入 Actor，采样连续动作 a，环境返回 s_next, r, done。

  2. 写入 Replay Buffer

    保存 transition：(s, a, r, s_next, done)。这批数据以后可以被反复抽样，不要求来自最新策略。

  3. 随机抽 mini-batch

    从 replay buffer 抽样，打破时间相关性。典型 batch size 是 256 或更大。

  4. 计算 soft Q target

    用 target Q 网络估计下一状态价值，同时减去 entropy 温度项。

    采样下个动作a' ~ π(·|s') soft valueV(s') = min(Q1,target(s',a'), Q2,target(s',a')) - α log π(a'|s') Q targety = r + γ(1-done)V(s')

  5. 更新两个 Q 网络

    让 Q1(s,a) 和 Q2(s,a) 都靠近 target y。

    Q 损失LQ = MSE(Q1(s,a), y) + MSE(Q2(s,a), y)

  6. 更新 Actor

    Actor 想让动作 Q 值高，同时保持 entropy。因为 optimizer 最小化 loss，所以写成下面这个形式。

    Actor lossLπ = E[α log π(a|s) - min(Q1(s,a), Q2(s,a))]

  7. 更新温度 α

    自动温度调节会让 entropy 接近目标 entropy。探索太少就增大 α，探索太多就减小 α。

    α lossLα = E[-α(log π(a|s) + target_entropy)]

  8. 软更新 target Q

    target Q 不直接复制当前 Q，而是缓慢靠近，减少 bootstrap 目标抖动。

    soft updateθtarget ← τθ + (1-τ)θtarget

SAC 每个 loss 到底在管什么

损失 更新谁 目标 直觉
Q loss Q1、Q2 让 Q(s,a) 接近 soft Bellman target。 Critic 学会评价动作到底值多少。
Actor loss Actor 选择高 Q 动作，同时保留 entropy。 既要赚钱，也别太早只会一种动作。
Alpha loss 温度 α 让策略 entropy 接近目标值。 自动调探索强度。
Soft update Target Q 让 target 网络慢慢跟随 Q 网络。 别让 bootstrap 目标跟着当前网络一起剧烈摆动。

SAC 核心代码骨架

这不是完整工程版，而是把 SAC 的 update 逻辑压缩成最重要的几行。先看懂这个，再写 IsaacLab 工程会顺很多。

# batch = replay_buffer.sample(batch_size) obs, actions, rewards, next_obs, dones = batch # 1. 计算 soft Q target with torch.no_grad(): next_actions, next_log_probs = actor.sample(next_obs) q1_next = q1_target(next_obs, next_actions) q2_next = q2_target(next_obs, next_actions) q_next = torch.min(q1_next, q2_next) - alpha * next_log_probs target_q = rewards + gamma * (1 - dones) * q_next # 2. 更新 Q1/Q2 q1 = q1_net(obs, actions) q2 = q2_net(obs, actions) q_loss = mse(q1, target_q) + mse(q2, target_q) q_optimizer.zero_grad() q_loss.backward() q_optimizer.step() # 3. 更新 Actor new_actions, log_probs = actor.sample(obs) q1_new = q1_net(obs, new_actions) q2_new = q2_net(obs, new_actions) q_new = torch.min(q1_new, q2_new) actor_loss = (alpha * log_probs - q_new).mean() actor_optimizer.zero_grad() actor_loss.backward() actor_optimizer.step() # 4. 自动温度 α alpha_loss = -(log_alpha * (log_probs + target_entropy).detach()).mean() alpha_optimizer.zero_grad() alpha_loss.backward() alpha_optimizer.step() alpha = log_alpha.exp() # 5. 软更新 target networks for p, p_targ in zip(q1_net.parameters(), q1_target.parameters()): p_targ.data.mul_(1 - tau) p_targ.data.add_(tau * p.data)

和 PPO 里的概念怎么对上

PPO 里的概念 SAC 里的对应 差别
RolloutBuffer ReplayBuffer PPO 临时保存一批 on-policy 数据；SAC 长期保存历史数据。
V(s) Q(s,a) PPO 常估状态价值；SAC 直接估状态-动作价值。
Entropy bonus 最大熵目标 PPO 里是辅助正则；SAC 里是算法核心。
Approx KL / clip target network / twin Q / α PPO 限制策略变化；SAC 通过 Q 学习和熵调节稳定更新。

实践里怎么判断 SAC 健康不健康

Q loss

Q loss 可以有波动，但长期爆炸说明 reward scale、learning rate 或 target 计算有问题。

Entropy / α

α 如果一直变大，说明策略太确定；α 如果一直变小，说明策略过于随机。

Replay Buffer

buffer 太小会过拟合近期数据，太大可能混入太旧的数据。机器人任务里通常从中等容量开始。

学习 SAC 的检查点：你能解释 replay buffer 为什么能复用旧数据、为什么要两个 Q、为什么 actor loss 是 α logπ - Q、为什么 target Q 要软更新。

PPO 让你理解稳定的 on-policy 更新；SAC 会带你进入 off-policy、最大熵和连续控制的核心地带。
